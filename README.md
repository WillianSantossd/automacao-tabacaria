# Python Web Scraper Project

This project is a Python web scraper developed using [Selenium](https://www.selenium.dev/) for web scraping and [SQLite3](https://docs.python.org/3/library/sqlite3.html) for database management.

## Installation

To get started with this project, you need to have Python and pip installed on your machine:

1. Download and install Python from [python.org](https://www.python.org/downloads/).
2. Verify the installation by running the following commands:
   ```bash
   python --version
   pip --version
   ```

3. Install the necessary packages:
   ```bash
   pip install selenium
   ```

## SQLite Database Overview

This project uses SQLite3 to manage data collected from web scraping. SQLite is a lightweight database that is built into Python, making it easy to set up and use.

## Generating Excel Reports

After scraping data, you can generate Excel reports using libraries such as [pandas](https://pandas.pydata.org/) and [openpyxl](https://openpyxl.readthedocs.io/en/stable/). Here's an example command to install these libraries:
```bash
pip install pandas openpyxl
```

This project is developed using [Visual Studio Code](https://code.visualstudio.com/) (VSCode). Make sure to configure the Python extension for better development experience.
